01 · Overview

Designing molecular glues that make a cell destroy PPIL4.

A molecular glue degrader (MGD) recruits a disease protein to the E3 ligase cereblon (CRBN) so the cell tags it for destruction. This project computationally designs and ranks candidate glues for the target PPIL4, validated against the cryo-EM reference structure 9DWV, and turns the ranking into an orderable buy list.

The one-line result

Under one locked, reproducible protocol, 18 candidate glues were docked into the CRBN·PPIL4 ternary complex. A key control shows a single docking score cannot rank glue activity — so the buy list is chosen across independent structural axes, to be settled by the wet lab.

02 · Target & Mechanism

A glue is a bridge — one end grips CRBN, the other grips PPIL4.

Degradation needs both ends. That two-arm logic drives the whole design.

CRBN — the E3 ligase

The glutarimide warhead (from thalidomide) sits in cereblon's tri-tryptophan degron pocket. This end is the same for every candidate.

The new interface

The glue creates a surface that recruits PPIL4 — a ternary complex CRBN·glue·PPIL4 that does not form without the glue.

PPIL4 — the target

The real interface is on PPIL4's RRM domain (residues 249–279 from 9DWV), not the cyclophilin/PPIase domain — a correction the reference structure made possible.

Why molecular glues

Unlike an inhibitor that must block a pocket, a glue only has to bring two proteins together; the cell's own machinery does the rest, catalytically. PPIL4 has no classic druggable site, which makes degradation an especially attractive route.

03 · Computational Pipeline

From 2,500 analogs to a ranked, reproducible shortlist.

Every parameter is fixed in a version-controlled protocol lock.

1 · Library

RDKit enumerates analogs on a confirmed glue scaffold, keeping the glutarimide fixed and varying the target-facing arm (2,500 molecules).

2 · Pre-filter

A random-forest CRBN-binder classifier (trained on ChEMBL) and AutoDock Vina triage the library into docking candidates.

3 · Ternary docking

HADDOCK3 v2026.7.0 docks CRBN + glue + PPIL4 together — rigidbody (1000) → flexref → emref → clustfcc, with fixed restraints and seed 42.

The locked protocol

Candidates are scored by the mean of their ten best HADDOCK scores. The protocol is validated by a positive control: the known glue FPFT-2216 reproduces the 9DWV binding mode (DockQ 0.38). Fixed restraints, pinned software version and a fixed seed make every run reproducible from the repository.

04 · Results & Buy List

The score can't tell a glue from a broken glue.

A des-glutarimide negative control scores as well as the real glue — so we buy across the axes.

The negative control that cannot anchor in CRBN (−112) scores like the real glue FPFT-2216 (−111): the HADDOCK score tracks interface size, not the degron mechanism. The buy list therefore mixes all-round winners with single-axis extremes, each a small experiment for the wet lab.

05 · MNAT1 · Next Target

A second target, guided by a known degron and a known glue.

Not a blind target: same machinery, new input.

The site

The degron is the G-loop glycine G50 (window N45–P52), a β-hairpin in the N-terminal RING domain; AlphaFold pLDDT ≈ 90.

The positive control

SJ6986 — a CRBN glue already shown to degrade MNAT1 (PubChem CID 155925914) — anchors the guided docking.

The reuse

The same CRBN degron-pocket restraints as PPIL4; only the target-side restraint (G50) changes. MNAT1 and PPIL4 come from the same landmark paper (Petzold et al., Science 2025).
